# Copycat: Cutaways / 伪装方块：切面伪装

The mod provides the Cutaway Copycat—a copycat block formed by slicing a piece away from a complete cube with a plane. The player selects three points along the cube's edges to define the plane in any orientation, then selects a fourth point on one of its faces to choose which side remains. The retained exterior faces and the newly exposed cut surface together form the block's final appearance.

The mod also provides a no-collision version. For both blocks, the placement grid resolution is configurable on the client.

This mod was developed with AI assistance and has not undergone sufficient review. Back up your worlds before use, and it is not recommended for use on public multiplayer servers.

Depends on: [Create: Copycats+](https://github.com/copycats-plus/copycats)
